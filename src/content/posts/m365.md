### Objectifs pédagogiques

- Préparer un environnement Microsoft 365 au déploiement de Microsoft 365 Copilot
- Administrer Microsoft Copilot et Microsoft 365 Copilot dans un contexte d’entreprise
- Appliquer les principes de Confiance Zéro, de sécurité et de conformité à Microsoft 365 Copilot
- Gérer les paramètres, l’accès web, les usages Teams et la supervision de Microsoft 365 Copilot
- Suivre l’adoption, la valeur et les interactions de Microsoft 365 Copilot dans l’organisation
- Préparer et administrer l’extensibilité de Microsoft 365 Copilot avec agents, connecteurs Microsoft Graph et plug-ins

### Programme détaillé

#### Préparer votre organisation à Microsoft 365 Copilot (2h00)

- Implémenter Microsoft 365 Copilot
- Examiner la sécurité des données et la conformité dans Microsoft 365 Copilot
- Remplir les conditions préalables pour Microsoft 365 Copilot
- Implémenter des outils de gestion avancée SharePoint pour la préparation à Microsoft 365 Copilot
- Préparer vos données pour les recherches dans Microsoft 365 Copilot
- Protéger vos données Microsoft 365 Copilot avec les outils de sécurité Microsoft 365
- Attribuer vos licences Microsoft 365 Copilot
- Étendre Microsoft 365 Copilot
- Favoriser l’adoption de Microsoft 365 Copilot dans toute votre organisation
- Examiner comment Microsoft 365 Copilot utilise les données métier, protège les données sensibles, applique les contrôles d’isolation et répond aux exigences de conformité

#### Gérer l’administration de Microsoft 365 Copilot (3h00)

- Appliquer les principes de Confiance Zéro à Microsoft 365 Copilot
- Gérer Microsoft Copilot
- Gérer Microsoft 365 Copilot
- Déployer ou valider la protection des données, l’identité et l’accès, les stratégies de protection des applications, la protection des appareils, les services de protection contre les menaces, la collaboration sécurisée Teams et les autorisations minimales sur les données
- Comparer Microsoft Copilot et Microsoft 365 Copilot
- Explorer Microsoft Copilot avec protection des données d’entreprise
- Gérer Microsoft Copilot dans Microsoft Edge
- Gérer Microsoft Copilot sur les appareils mobiles
- Gérer les paramètres de Microsoft 365 Copilot
- Gérer l’accès web pour Microsoft 365 Copilot
- Gérer Copilot pour les réunions et événements Microsoft Teams
- Explorer les protections de données Microsoft Purview pour les applications d’IA
- Sécuriser les données pour les applications IA avec DSPM pour l’IA
- Surveiller la valeur de Microsoft 365 Copilot via le tableau de bord Copilot
- Suivre la préparation et l’utilisation de Microsoft 365 Copilot
- Surveiller les interactions Copilot avec la conformité des communications
- Supprimer l’historique d’interaction Microsoft 365 Copilot
- Travail pratique :  
    Simulation : passer en revue les paramètres de Microsoft 365 Copilot  
    Simulation : gérer l’accès web et d’autres paramètres de stratégie Copilot  
    Simulation : gérer Copilot dans le Centre d’administration Teams  
    Simulation : découvrir les risques potentiels de sécurité des données dans les interactions Microsoft 365 Copilot à l’aide de DSPM pour l’IA  
    Simulation : créer une stratégie de conformité qui détecte les interactions Microsoft 365 Copilot

#### Préparer l’extensibilité de Microsoft 365 Copilot (2h00)

- Notions fondamentales de l’extensibilité de Microsoft 365 Copilot
- Choisir un chemin de développement de l’extensibilité de Copilot
- Gérer l’extensibilité de Microsoft 365 Copilot
- Comprendre comment Copilot et les agents travaillent ensemble
- Ajouter des connaissances avec les connecteurs Graph
- Ajouter des compétences avec des plug-ins
- Créer votre propre copilote
- Choisir entre agent déclaratif et agent de moteur personnalisé
- Examiner les avantages, limites et chemins de développement de l’extensibilité
- Gérer les assistants Copilot dans les applications intégrées
- Créer une connexion entre une source de données et un connecteur Microsoft Graph
- Surveiller les connecteurs Microsoft Graph
- Gérer l’affichage du contenu des connecteurs Microsoft Graph dans Microsoft 365 Copilot
- Travail pratique :  
    Démonstration : gérer des assistants Copilot dans le Centre d’administration Microsoft 365  
    Démonstration : créer une connexion avec un connecteur Microsoft Graph  
    Démonstration : surveiller les connecteurs Microsoft Graph  
    Démonstration : gérer l’affichage du contenu des connecteurs Microsoft Graph
